# OX-Alpha for Chrome / Edge

- **قائمة الزر الأيمن**: اسأل عن النص المحدد، أو احفظه كملف في المشروع، أو أرسل الصفحة كاملة بصيغة Markdown إلى `clips/`.
- **النافذة المنبثقة** (`Alt+Shift+X`): سؤال سريع، أو فتح OX-Alpha، أو عرض حالة المشروع.
- الاتصال يتم عبر جسر `postMessage` في تبويب OX-Alpha المفتوح، ويُحمى برمز API (فعّله من مركز التكاملات ← REST API).

## التثبيت

1. افتح `chrome://extensions` وفعّل **وضع المطوّر**.
2. اختر **تحميل إضافة غير مضغوطة** ثم مجلد `extensions/chrome`.
3. من الإعدادات: ضع رابط OX-Alpha ورمز API.
