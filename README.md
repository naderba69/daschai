# OX-Alpha Workbench Pro

منصة ويب عربية لهندسة البرمجيات وإدارة المشاريع، تجمع محادثات الذكاء الاصطناعي، أدوات GitHub، محرر الأكواد، وتشغيل JavaScript وPython في واجهة واحدة متجاوبة.

## أحدث إصدار: v2.17.0

- **تحرير رسائل المستخدم وإعادة إرسالها**، مع حفظ المسارات السابقة والتنقل بينها دون فقد الردود أو الرسائل التي تلتها.
- **إعادة توليد ردود المساعد** بالنموذج نفسه أو اختيار نموذج آخر.
- **تفريع المحادثة** من أي رسالة إلى جلسة مستقلة، وحذف الرسالة مع إمكانية التراجع.
- واجهة مهيأة للهاتف واللوحي وسطح المكتب، بثيمين داكن وفاتح.

التفاصيل الكاملة في [سجل التغييرات](CHANGELOG.md).

## أبرز الإمكانات

- محادثة متعددة النماذج عبر OpenRouter، مع بث الردود، بحث ويب، أوضاع محادثة، وإرفاق ملفات ونصوص وصور.
- إدارة جلسات المحادثة والبحث فيها وتنظيمها، مع حفظ محلي في المتصفح وIndexedDB.
- محرر واستوديو للمشروع، تشغيل JavaScript وPython، أدوات اختبار وتصحيح، ودعم GitHub.
- أدوات تصدير واستيراد الملفات والمشاريع، وعرض Markdown ومخططات Mermaid.
- إعدادات للثيم والاختصارات وإمكانية تثبيت التطبيق كتطبيق ويب تقدمي (PWA).

## التشغيل محلياً

المتطلبات: Node.js 18 أو أحدث وnpm.

```bash
npm ci
npm run build
npm run preview
```

افتح العنوان المحلي الذي يعرضه `serve` (عادةً `http://localhost:3000`). لتشغيل مجموعة الفحوص:

```bash
npm test
```

تتضمن المجموعة بناء الإنتاج، فحوص التهيئة، واختبارات jsdom للميزات والتجاوب.

## نشر نسخة على Vercel

1. اربط مستودع `naderba69/daschai` بحسابك في Vercel.
2. يحدد `vercel.json` إعدادات البناء والمخرجات: `npm run vercel-build` ومجلد `public/`.
3. انشر الفرع المطلوب من لوحة Vercel؛ لا حاجة إلى رفع ملفات البناء يدوياً.

## إعداد الذكاء الاصطناعي

أدخل مفتاح OpenRouter من إعدادات التطبيق واختر النموذج. اتصال النماذج يتم من المتصفح مباشرةً إلى مزود الخدمة؛ تُحفظ إعدادات التطبيق محلياً في المتصفح، فاستعمل مفتاحك الشخصي على جهاز موثوق ولا تشاركه في المحادثات أو المستودعات.

## المساهمة والتحديث

```bash
git clone https://github.com/naderba69/daschai.git
cd daschai
npm ci
npm test
```

لإرسال تعديل، أنشئ فرعاً من المستودع وافتح Pull Request؛ لا تستخدم `git push --force` إلى `main`.
