# OX-Alpha CLI

```bash
export OPENROUTER_API_KEY=sk-or-...
npx github:naderba69/daschai ask "ما الخطأ هنا؟" src/app.js
npx github:naderba69/daschai review
npx github:naderba69/daschai commit --yes
npx github:naderba69/daschai init react my-app
npx github:naderba69/daschai open
```

بدون أي اعتماديات (Node 18+). يمكن أيضاً تشغيله مباشرة: `node cli/ox-alpha.js help`.
