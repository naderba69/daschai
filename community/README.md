# برومبتات المجتمع

ملف `prompts.json` هو مصدر **سوق البرومبتات** في OX-Alpha (مركز التكاملات ← الذكاء ← سوق البرومبتات) وفي أمر `ox-alpha prompts`.

للمساهمة بـ برومبت جديد: من داخل OX-Alpha اضغط «انشر برومبتاً» (يفتح Issue جاهزاً)، أو أرسل Pull Request يضيف عنصراً بالشكل:

```json
{ "id": "slug-فريد", "title": "العنوان", "cat": "code", "text": "نص البرومبت (20 حرفاً على الأقل)", "tags": ["..."], "stars": 0, "author": "github-user" }
```
